## 🌟 Key Features

- **⚡ Real-Time Stockfish 18 NNUE Move Arrows**: Instant vector move arrows drawn on the Chess.com board without consuming local CPU or battery.
- **🚀 Ultra-Fast Real-Time Engine**: High-speed position calculation with zero lag.
- **👑 Smart Promotion Advisor**: Analyzes all 4 promotion options (Queen, Rook, Bishop, Knight) to detect winning tactics and avoid stalemate traps.
- **🎯 Dynamic Move Quality & History**: Automatic move classification (Best, Good, Inaccuracy, Mistake, Blunder) with real-time centipawn evaluation.
- **📊 Real-Time Win Rate & Eval Chart**: Live interactive evaluation curve and percentage win probability updated on every move.
- **📥 1-Click PGN Export**: Export full game notation with evaluation tags directly to PGN format.
- **🕶️ Instant Stealth Mode (`Q` key)**: Hide/unhide arrows and dashboard overlay in 0ms.
- **🎨 Pure Black Aesthetics & Themes**: Multiple themes (Emerald, Electric Cyan, Cyber Purple, Gold) and arrow styles (Solid, Neon, Cyber Dashed, Stealth Dot).

## 🚀 Installation Guide

### Load Unpacked Extension (Chrome / Brave / Edge / Opera / Kiwi)

1. **Download & Extract**:
   - Download the latest ZIP release from our [Telegram Channel](https://t.me/ibrprojects/4).
   - Extract the folder on your computer.

2. **Open Extensions Page**:
   - In Chrome / Brave / Edge, navigate to: `chrome://extensions/`
   - Enable **Developer mode** toggle in the top-right corner.

3. **Load Extension**:
   - Click **Load unpacked**.
   - Select the extracted `IBR_Chess_Engine` folder.

4. **Play on Chess.com**:
   - Open any game, puzzle, or analysis board on [Chess.com](https://www.chess.com).
   - The engine automatically detects the board and draws best-move arrows in real-time!

## ⚙️ Configuration & Customization

Click the **IBR Chess Engine** icon in your browser toolbar to customize:
- **Calculation Depth**: Adjust from Depth 8 to Depth 18 NNUE.
- **Arrow Styles**: Solid Black Vector, Neon, Cyber Dashed, or Stealth Dot.
- **Arrow Sizing**: Scale arrow shaft and head dimensions to match your display.
- **Color Themes**: Pure Black, Emerald Green, Electric Cyan, Cyber Pink, Gold.
- **Sound Alerts**: Audio cue when new engine moves are calculated.
